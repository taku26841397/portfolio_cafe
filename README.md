# ☕ カフェサイト（ポートフォリオ作品）

静的 HTML / CSS / JavaScript を用いて制作したカフェの紹介サイトです。  
店舗紹介、メニュー、イベント情報、ニュース、コーヒー紹介など、実際のカフェサイトを想定した構成でデザインしました。

---

## 🌐 公開 URL
https://portfolio-cafe.pages.dev/

---

## 🛠 使用技術
- HTML5
- CSS3
- JavaScript
- Cloudflare Pages（公開）

---

## 📌 ページ構成
- index.html：トップページ  
- shop_introduction.html：店舗紹介（イベント、ニュース、お知らせ）  
    - event.html：イベント  
    - news.html：ニュース  
    - notice.html：お知らせ 
- menu.html：メニュー一覧  
- coffee.html：自家焙煎コーヒーの紹介   
- mente.html：メンテナンス・更新情報  
- css/：スタイルシート  
- js/：JavaScript  
- image/：画像素材  

---

## 🎨 デザインのポイント  
- JavaScript による動きのある UI  
- メニューやコーヒー紹介を視覚的に分かりやすく配置    
- HTML / CSS の基本を押さえたシンプルな構造
